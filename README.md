# dev_cli
An AI-Native Developer CLI.

Alright, so this is my version of an Open-Code like thing, but it has other tools. Said tools include base64 encode/decode, and I do not really remember what else. I was gonna add more but I ended up forgetting, and rn I just want to give the public access. As of what I know, it should be able to be run on Windows/Linux but I can only verify Mac. It has an AI system, and you can either use an OpenAI Endpoint or Ollama. More info can be found by typing "help" and you can install it right here --> **https://pypi.org/project/dev-terminal-app/**

Quick Requirement:  Ollama must be installed and running on your device. You can get it here --> **https://ollama.com/download**
